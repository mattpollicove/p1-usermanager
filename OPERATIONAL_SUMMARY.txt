🎯 HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

RECOMMENDED (Clean Start - Closes Old Instances):
   $ ./cleanup_and_run.sh
   
   This one command:
   • Finds any running app instances
   • Terminates them cleanly
   • Activates virtual environment
   • Installs missing dependencies
   • Starts fresh app

CROSS-PLATFORM (Clean Start):
   $ python3 cleanup_and_run.py
   
   Same as above but platform-independent

STANDARD (If No Old Instances):
   $ ./run.sh              (Bash)
   $ python3 run.py        (Python)
   
   Faster startup, skips termination check

✅ RULE 1: Close Old Instances Before Starting New Ones
   Use: ./cleanup_and_run.sh
   Or:  python3 cleanup_and_run.py
   
   When:
   • Making code changes
   • Testing new features
   • After crashes/errors
   • When switching profiles
   • Before deployment

✅ RULE 2: Check for Running Instances
   Command: ps aux | grep "python3 app.py"
   Shows: All running app instances with PIDs
   
✅ RULE 3: Use Synchronous Methods in UI
   When: Writing UI code that needs to call async operations
   Use: .get_token_sync() instead of asyncio.run()
   Why: Avoids event loop conflicts with PySide6
